# 대포 룰렛 · 랜덤 추첨 웹 앱

여러 사람의 이름을 입력하면, 대포가 구슬을 하나씩 발사해 여러 장애물(핀, 회전 로터)을 통과시키고
가장 마지막에 멈추는 구슬의 주인공을 당첨자로 뽑아주는 웹 앱입니다.

Google Apps Script 웹 앱으로 구성되어 있으며 아래 두 파일로 이루어져 있습니다.

- `Code.gs` — `doGet()` 진입점. `index.html`을 렌더링합니다.
- `index.html` — 대포, 물리 시뮬레이션(Matter.js), 추첨 로직을 포함한 전체 UI.

## 배포 방법

1. [script.google.com](https://script.google.com) 에서 새 프로젝트를 만듭니다.
2. 기본 생성된 `Code.gs` 내용을 이 저장소의 `Code.gs` 내용으로 교체합니다.
3. 파일 추가 → HTML 파일을 선택하고 파일 이름을 `index` 로 지정한 뒤, 이 저장소의 `index.html` 내용을 붙여넣습니다.
4. 우측 상단 배포 → 새 배포 → 유형에서 "웹 앱"을 선택합니다.
5. 액세스 권한을 설정하고 배포하면 발급된 URL로 접속할 수 있습니다.

## 사용법

1. 왼쪽 패널의 입력창에 참가자 이름을 한 줄에 한 명씩(또는 쉼표로 구분해) 입력합니다.
2. "추첨 시작" 버튼을 누르면 대포가 좌우로 조준하며 구슬을 순서대로 발사합니다.
3. 구슬은 핀과 회전 장애물을 통과해 바닥에 도착하고, 도착 순서가 왼쪽에 실시간으로 표시됩니다.
4. 모든 구슬이 멈추면 가장 마지막에 도착한 구슬의 주인공이 🏆 당첨자로 발표됩니다.
5. "다시 추첨하기"를 눌러 같은 명단으로 다시 진행할 수 있습니다.
