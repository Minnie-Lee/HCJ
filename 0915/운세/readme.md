# 🔮 오늘의 운세를 알려주는 나나도사

> **"당신의 기운을 담아 오늘의 운세를 확인해보세요."**  
> 사용자의 기본 정보(이름, 생년월일, 성별)와 오행의 기운(불, 물, 나무, 땅, 바람)을 기반으로 오늘의 운세를 맞춤 추천해 주는 웹 서비스입니다.

---

## 📌 프로젝트 소개
바이브 코딩 예제 프로젝트인 **나나도사 운세관**은 누구나 웹 브라우저만으로 손쉽게 운세를 점쳐볼 수 있는 단일 파일(Vanilla HTML/CSS/JS) 기반의 인터랙티브 웹 애플리케이션입니다.

화사하고 부드러운 파스텔톤 배경과 글래스모피즘(Glassmorphism) 스타일을 적용하여 시각적으로 편안하고 감성적인 사용자 경험을 제공합니다.

---

## ✨ 주요 기능

1. **사용자 정보 입력**
   - **이름**: 맞춤형 결과 출력을 위한 사용자 이름 입력
   - **생년월일 및 나이 자동 계산**: 사용자가 생년월일을 선택하면 현재 날짜 기준의 만 나이가 자동으로 계산되어 표시
   - **성별 선택**: 버튼 토글형 인터페이스 (남성 / 여성 / 기타)

2. **5원소(오행) 인터랙티브 선택**
   - 마음이 끌리는 하나의 원소를 탭하여 선택 가능:
     - 🔥 **불**: 열정과 도전
     - 💧 **물**: 지혜와 치유
     - 🌲 **나무**: 성장과 생명
     - ⛰️ **땅**: 안정과 결실
     - 🍃 **바람**: 자유와 변화

3. **운세 확인 및 결과 출력**
   - 필수 정보 입력 여부 검증 (유효성 검사)
   - 선택한 원소 기반의 랜덤 오늘의 운세 메시지 출력
   - 부드러운 페이드 인(Fade-in) 애니메이션 결과 박스

---

## 🎨 디자인 특징

- **파스텔톤 그라데이션**: 핑크, 라벤더, 스카이블루 계열의 차분하고 산뜻한 색조 조합
- **배경 블러 효과(Blur Orbs)**: 부드럽게 퍼지는 원형 빛망울을 활용한 몽환적 배경 연출
- **글래스모피즘(Glassmorphism)**: 반투명 유리 카드 질감(`backdrop-filter: blur()`)과 은은한 그림자 처리
- **모바일 반응형 레이아웃**: 스마트폰, 태블릿, PC 어디서나 쾌적하게 동작하는 반응형 카드 구조


## 🚀 실행 방법

별도의 서버 설치나 패키지 매니저(npm 등) 설치가 필요하지 않습니다.

1. `index.html` 파일을 다운로드하거나 생성합니다.
2. 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등 웹 브라우저에서 `index.html`을 더블 클릭하여 실행합니다.
3. 이름, 생년월일, 성별을 입력하고 원소를 고른 뒤 **"오늘의 운세 확인하기"** 버튼을 누릅니다.

---

## 🛠️ 기술 스택

- **HTML5**: 구조화된 폼 및 시맨틱 태그
- **CSS3**: 모던 Flexbox/Grid 레이아웃, 트랜지션, 애니메이션, 글래스모피즘 스타일링
- **Vanilla JavaScript**: 실시간 나이 계산, 상태 관리 및 난수 기반 운세 렌더링
