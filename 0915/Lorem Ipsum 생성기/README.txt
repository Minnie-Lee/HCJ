Lorem Ipsum Generator - Google Apps Script 웹앱

기능
- 처음 150자 Lorem Ipsum 표시
- 슬라이더 최소 10자 / 최대 5,000자
- 슬라이더를 움직이는 즉시 글자 수에 맞춰 내용 변경
- 150자로 초기화
- 생성된 텍스트 복사
- 밝은 프리미엄 UI와 마우스 반응형 그라데이션

설치
1. Google Apps Script 새 프로젝트 생성
2. Code.gs 내용을 붙여넣기
3. HTML 파일을 index로 생성하고 index.html 내용을 붙여넣기
4. 배포 > 새 배포 > 웹 앱
5. 실행 사용자: 나
6. 액세스 권한을 원하는 범위로 설정
7. 배포된 웹앱 URL 접속
