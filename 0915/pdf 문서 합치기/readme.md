프롬포트 : 여러개의 PDF 문서 합치기, 주요기능은 여러개의 PDF 파일을 업로드하면 하나의 문서 파일로 합쳐줍니다. 예제 코드는 https://nanalab.kr/merge_pdf/ 이거 참고해서 만들어줘. 사용자가 여러 개의 PDF 파일을 업로드하면, 그걸 합쳐서 하나의 문서 파일로 병합해 주는 웹 앱 만들어줘. HTML, CSS, JS만 사용해서 만들어줘, 디자인도 추가해줘.

- 주요 기능
100% 클라이언트 사이드 처리: 업로드된 문서가 외부 서버로 전송되지 않고 브라우저 내부 메모리에서 즉시 병합되어 개별 정보 유출 위험이 없습니다.
드래그 앤 드롭 지원: 편리한 Drag & Drop 인터페이스로 여러 파일들을 한 번에 등록할 수 있습니다.
문서 순서 변경 및 삭제: 등록된 파일 리스트에서 위/아래 이동 버튼(`▲`, `▼`)을 이용해 병합될 순서를 조정하거나 개별 제거가 가능합니다.
저장 파일명 직접 지정: 병합 후 생성될 PDF 파일 이름을 사용자가 자유롭게 커스텀할 수 있습니다.
모던 Glassmorphic UI: 은은한 파스텔 그라데이션 배경과 직관적인 사용자 경험을 제공합니다.

- 사용 기술 (Tech Stack)
HTML5 / CSS3 / JavaScript (Vanilla JS)
[pdf-lib](https://pdf-lib.js.org/): 브라우저 단에서 PDF 병합 및 조작 처리
Font Awesome 6: 웹 아이콘 적용

- 시작하기
별도의 빌드 과정이나 서버 설정(Node.js 등)이 전혀 필요하지 않습니다.
1. 이 레포지토리를 클론(Clone)하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 실행합니다.
