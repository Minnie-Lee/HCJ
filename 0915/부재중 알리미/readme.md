프롬포트 : 금방 돌아올게요! 부재 중 알리미. 잠시 자리를 비웠을 때, 화면에 정보를 표기해 주는 앱을 만들어줘. 사용자 동작 - 일정 입력, 어넺 다시 돌아오는지 입력, 기타 문구 입력 후 확인 버트늘 누르면 깔끔하고 아름다운 그라데이션 애니메이션 표시. 일정, 돌아오는 시간과 카운트다운, 기타 안내 문구라 출력되도록 만들어줘. 일정을 제일 큰 글자로

- 부재 중 알리미 (Away Notice Screen)

자리를 잠시 비울 때 모니터 화면에 일정, 복귀 예정 시간, 실시간 카운트다운 및 안내 문구를 깔끔하고 아름다운 애니메이션 배경과 함께 표시해 주는 단일 페이지 웹 애플리케이션입니다.

- 주요 특징
단일 파일(Single HTML)**: 별도의 설치나 서버 설정 없이 `index.html` 파일 하나만 브라우저로 열어서 바로 사용할 수 있습니다.
최우선 정보 강조**: 설정한 일정/사유가 화면 중앙에 가장 큰 타이포그래피로 강조되어 표시됩니다.
실시간 카운트다운**: 복귀 예정 시간까지 남은 시간을 초 단위로 실시간 계산하여 출력합니다.
아름다운 그라데이션 애니메이션**: 4가지 파스텔/네온 톤 색상이 유기적으로 변화하는 Smooth Mesh Gradient 배경을 제공합니다.
글래스모피즘 UI**: 반투명 유리 느낌(Frosted Glass)의 모던한 디자인 요소를 적용했습니다.
정갈한 텍스트 디자인**: 이모지나 불필요한 특수문자를 배제하고 타이포그래피 위주의 깔끔한 레이아웃을 갖추었습니다.

- 구성 요소

| 화면 구분 | 구성 항목 | 설명 |
| :--- | :--- | :--- |
| 설정 화면 (Form View) | 일정 또는 사유 | 부재 사유 입력 (예: 점심 식사, 외부 미팅) |
| | 복귀 예정 시간 | 시간 선택 파서 (기본값: 현재 시간 기준 1시간 후) |
| | 기타 안내 문구 | 비상 연락망, 전달 사항 등 |
| 부재 화면 (Display View) | 상단 상태 표기 | '현재 자리 비움 중' 상태 뱃지 |
| | 중앙 대형 타이틀 | 지정한 일정을 최상위 크기로 표시 |
| | 복귀 시간 & 카운트다운 | 예정 시간 및 남은 시간(HH:MM:SS) 실시간 표시 |
| | 하단 안내 문구 카드 | 반투명 카드 형태의 기타 안내 문구 |
| | 복귀/수정 버튼 | 클릭 시 설정 화면으로 원클릭 복귀 |

- 기술 스택
HTML5 & JavaScript (ES6+)
Tailwind CSS (CDN): 레이아웃 및 반응형 스타일링
Google Fonts (Pretendard): 가독성 높고 정갈한 한글 폰트 적용
CSS3 Animation & Glassmorphism: `linear-gradient` 애니메이션 및 `backdrop-filter` 효과

-  사용 방법

1. 본 저장소의 `index.html` 파일을 다운로드합니다.
2. `index.html` 파일을 크롬, 엣지, 웨일, 사파리 등 웹 브라우저로 실행합니다.
3. 일정/사유, 복귀 예정 시간, 안내 문구를 입력합니다.
4. [알림 화면 시작하기] 버튼을 누르면 부재 중 화면이 전체 화면 모드로 실행됩니다.
5. 자리에 돌아온 후 하단의 [자리 복귀 / 내용 수정] 버튼을 클릭하여 설정 화면으로 되돌아갑니다.
