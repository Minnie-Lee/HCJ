# 오디오 에디터 웹 앱

MP3, WAV 등 오디오 파일을 업로드해 파형을 보면서 구간을 자르고(trim), 볼륨을 조절하고,
원하는 형식(WAV / MP3)으로 변환해 내려받을 수 있는 웹 앱입니다. 모든 처리는 브라우저 안에서
Web Audio API와 lamejs(순수 자바스크립트 MP3 인코더)로 이루어지며, 서버로 파일이 업로드되지 않습니다.

Google Apps Script 웹 앱으로 구성되어 있으며 아래 두 파일로 이루어져 있습니다.

- `Code.gs` — `doGet()` 진입점. `index.html`을 렌더링합니다.
- `index.html` — 업로드, 파형 표시, 트림/볼륨/포맷 변환 로직을 포함한 전체 UI.

## 배포 방법

1. [script.google.com](https://script.google.com) 에서 새 프로젝트를 만듭니다.
2. 기본 생성된 `Code.gs` 내용을 이 저장소의 `Code.gs` 내용으로 교체합니다.
3. 파일 추가 → HTML 파일을 선택하고 파일 이름을 `index` 로 지정한 뒤, 이 저장소의 `index.html` 내용을 붙여넣습니다.
4. 우측 상단 배포 → 새 배포 → 유형에서 "웹 앱"을 선택합니다.
5. 액세스 권한을 설정하고 배포하면 발급된 URL로 접속할 수 있습니다.

## 기능

1. **포맷 변환** — WAV(무손실) 또는 MP3(128/192/256/320kbps)로 내보내기
2. **볼륨 조절** — 0~200% 슬라이더, 실시간 미리듣기와 dB 표시
3. **구간 trim** — 파형을 드래그해 시작/끝 지점을 선택하고 선택 구간만 재생·추출

## 사용법

1. 업로드 영역을 클릭하거나 오디오 파일을 끌어다 놓습니다.
2. 파형이 표시되면 원하는 구간을 드래그해 선택합니다 (핸들을 다시 드래그하면 미세 조정 가능).
3. 볼륨 슬라이더로 소리 크기를 조절합니다.
4. 내보내기 형식(WAV/MP3)과 필요 시 비트레이트를 선택합니다.
5. "다운로드"를 누르면 선택 구간과 볼륨이 반영된 파일이 저장됩니다.
