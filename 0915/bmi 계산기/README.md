# 체중 계산기 (Google Apps Script 웹앱)

키, 몸무게, 성별을 입력하면 BMI와 표준체중을 계산하고, 표준체중 대비 90% · 100% · 110% 지점까지 몇 kg을 빼거나 찌워야 하는지 보여주는 웹앱입니다.

## 파일 구성

- `code.gs` — Apps Script 서버 진입점 (`doGet`이 `index.html`을 렌더링)
- `index.html` — 화면 전체 (HTML/CSS/JS 단일 파일)
- `README.md` — 이 문서

## 배포 방법

1. [script.google.com](https://script.google.com) 에서 새 프로젝트를 만듭니다.
2. 기본 생성된 `Code.gs` 내용을 지우고 이 저장소의 `code.gs` 내용을 붙여넣습니다.
3. 왼쪽 파일 목록에서 `+` → HTML 선택 → 파일 이름을 `index`로 지정한 뒤, 이 저장소의 `index.html` 내용을 붙여넣습니다.
4. 우측 상단 **배포 → 새 배포**를 클릭합니다.
5. 유형에서 **웹 앱**을 선택합니다.
6. 실행 계정과 액세스 권한(예: 나만 사용 / 링크가 있는 모든 사용자)을 설정하고 **배포**를 누릅니다.
7. 발급된 웹 앱 URL로 접속하면 계산기가 열립니다.

## 계산 방식

- **BMI** = 몸무게(kg) ÷ 키(m)²
  - 18.5 미만: 저체중 / 18.5~22.9: 정상 / 23~24.9: 과체중 / 25~29.9: 비만 1단계 / 30 이상: 비만 2단계 이상
- **표준체중**
  - 남성: (키(cm) − 100) × 0.9
  - 여성: (키(cm) − 100) × 0.85
- **표준체중 대비 비율(%)** = 몸무게 ÷ 표준체중 × 100
  - 실제 BMI 지수는 보통 18~40 범위라 90 · 100 · 110이라는 값이 나올 수 없어, 요청하신 90 · 100 · 110 기준은 **표준체중 대비 비율(%)** 로 해석해 구현했습니다.
  - 각 비율(90% / 100% / 110%)에 해당하는 목표 체중을 계산하고, 현재 체중과의 차이를 감량/증량 kg으로 표시합니다.

입력값이 바뀌는 즉시(타이핑 중, 성별 전환 시) 자동으로 재계산되어 결과가 표시됩니다.

## 이 프로젝트를 만든 프롬프트

아래는 이 웹앱을 만들기 위해 실제로 주고받은 대화 프롬프트입니다.

> BMI 계산해 주는 웹 앱 만들어줘, 사용자 키, 몸무게, 성별을 입력받아서 BMI 계산해주고 BMI 90, 100,110 기준 몇kg까지 빼거나 찌워야 하는지 화면에 보여줘

> 계산까지 해주고 결과까지 나오게끔 만들어줘

> 그럼 이걸 code.gs, index.html 만들어주고 readme.md 파일을 만들어서 이 프롬프트 넣어서 한 파일에 넣어줘
