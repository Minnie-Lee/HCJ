# 🎬 Video to GIF Converter

> 웹 브라우저에서 서버 통신 없이 동영상을 간편하게 GIF 애니메이션으로 변환해 주는 클라이언트 사이드 웹 애플리케이션입니다.

---

## 📌 프로젝트 소개

본 웹페이지는 별도의 서버 업로드 없이 사용자의 로컬 브라우저 환경에서 동영상(Video) 파일을 읽어 프레임을 캡처하고, GIF 형식으로 인코딩하여 즉시 다운로드할 수 있도록 제작되었습니다.

- **브랜드 연동**: 상단 헤더의 로고 클릭 시 [NaNa Lab (nanalab.kr)](https://nanalab.kr) 공식 사이트로 연결됩니다.
- **반응형 & 모던 UI**: 카드 기반의 직관적인 디자인과 부드러운 애니메이션 효과를 제공합니다.

---

## ✨ 주요 기능 (Key Features)

1. **드래그 앤 드롭 파일 업로드**
   - 점선 영역으로 동영상 파일을 직접 끌어다 놓거나, `파일 업로드` 버튼을 눌러 탐색기에서 파일을 선택할 수 있습니다.
2. **동적 카드 생성 & 동영상 미리보기**
   - 파일 추가 시 즉시 리스트 카드가 생성되며, 원본 동영상의 첫 장면을 썸네일로 확인할 수 있습니다.
3. **실시간 변환 프로그레스 바**
   - 프레임 인코딩 진행 상황을 0%부터 100%까지 게이지 바와 퍼센트 텍스트로 실시간 표시합니다.
4. **GIF 썸네일 자동 전환 및 다운로드**
   - 변환이 완료되면 썸네일이 완성된 GIF 애니메이션으로 교체되며, `다운로드` 버튼이 활성화되어 원클릭 저장이 가능합니다.
5. **클라이언트 사이드 처리 (보안 및 프라이버시)**
   - 동영상 데이터가 외부 서버로 전송되지 않고 브라우저(Web Workers & Canvas) 내부에서 처리되므로 안전하고 빠릅니다.

## 🛠 기술 스택 (Tech Stack)

| 구분 | 기술 / 라이브러리 | 용도 |
| :--- | :--- | :--- |
| **Markup & Styling** | HTML5, CSS3 | 단일 페이지 레이아웃 및 반응형 스타일링 |
| **Logic** | Vanilla JavaScript (ES6+) | 파일 드래그 앤 드롭 이벤트, 비동기 카드 렌더링 |
| **GIF Processing** | [gifshot](https://github.com/yahoo/gifshot) (v0.3.2) | 브라우저 내 프레임 캡처 및 GIF 생성 라이브러리 |
