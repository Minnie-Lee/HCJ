# 모바일 청첩장 웹 페이지 (Mobile Wedding Invitation)

스마트폰 화면에 최적화된 심플하고 우아한 반응형 모바일 청첩장 웹 페이지입니다. 별도의 백엔드 구성 없이 HTML, Tailwind CSS, 바닐라 자바스크립트로 동작합니다.

---

## 📌 주요 기능

* **모바일 최적화 레이아웃**: 스마트폰 뷰포트에 맞춘 단일 컬럼 형태(최대 너비 448px)의 중앙 정렬 카드 디자인
* **실시간 D-Day 카운트다운**: 목표 일시(2099년 12월 26일 12:00)까지 남은 일, 시간, 분, 초를 1초마다 실시간으로 갱신하여 표시[cite: 2]
* **이미지 갤러리 그리드**: 단독 및 커플 사진을 감성적인 그리드 형태로 배치하며, 이미지 로드 실패 시 Placeholder 자동 대체 처리[cite: 2]
* **부드러운 페이드인 효과**: 페이지 진입 시 은은한 등장 애니메이션 적용[cite: 2]

---

## 🛠 기술 스택

* **HTML5**[cite: 2]
* **Tailwind CSS (CDN)**: 스타일링 및 반응형 그리드 구축[cite: 2]
* **Google Fonts**: `Noto Serif KR` (명조 계열 폰트 적용)[cite: 2]
* **Vanilla JavaScript**: 실시간 카운트다운 타이머 로직[cite: 2]
