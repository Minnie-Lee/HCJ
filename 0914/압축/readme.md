# 📁 Smart Doc Compressor

> 브라우저 기반의 클라이언트 사이드 경량화 문서 및 이미지 압축 웹 애플리케이션

**Smart Doc Compressor**는 별도의 서버 설치나 파일 업로드 없이 사용자의 웹 브라우저 내에서 직접 문서 및 이미지 파일의 용량을 경량화하는 웹 도구입니다.

## 📖 프로젝트 소개

문서 파일의 용량이 커지는 주원인은 본문 내 삽입된 고해상도 이미지와 리소스에 있습니다. 특히 이메일 발송 제한이나 웹 포털 업로드 용량 제한(예: 10MB~20MB)에 걸리는 문제를 해결하기 위해, 클라이언트 사이드에서 즉시 용량을 감축할 수 있도록 설계되었습니다.

* **100% 클라이언트 사이드 구동:** 민감한 문서 데이터가 외부 서버로 전송되지 않아 보안상 안전합니다.
* **사용자 친화적 인터페이스:** 드래그 앤 드롭 영역, 파일별 독립 프로그레스 바, 원클릭 다운로드를 지원합니다.

## 🚀 핵심 기능

### 1. 직관적인 UI & UX
* **드래그 앤 드롭(Drag & Drop):** 브라우저 화면 중앙 영역에 파일을 직접 끌어다 놓거나 클릭하여 선택 가능
* **멀티 파일 큐 & 프로그레스 바:** 여러 파일을 한 번에 업로드할 수 있으며, 각 파일마다 독립적인 진행 상태 및 진행률(%) 표기
* **네이밍 규칙 적용 다운로드:** 작업 완료 후 활성화되는 다운로드 버튼을 클릭하면 원본 파일명 앞에 `compressed_` 접두사를 붙여 자동 저장

### 2. 브라우저 실시간 이미지 압축
* **지원 포맷:** JPG, JPEG, PNG, WEBP
* **동작 원리:** HTML5 Canvas API를 통해 이미지를 디코딩한 뒤, 최적화된 해상도와 JPEG 압축 품질(Quality 0.6)을 적용해 바이트 크기를 대폭 감축

### 3. PDF 저화질 스캔본(Scanned-Copy) 압축
* **지원 포맷:** PDF
* **동작 원리:** 
  1. `PDF.js`를 이용해 업로드된 PDF의 페이지를 순차적으로 렌더링
  2. 각 페이지 캔버스를 JPEG 압축(품질 0.5) 형태로 스캔본 캡처
  3. `jsPDF`를 통해 캡처된 이미지들을 단일 PDF 파일로 재조합 및 출력하여 용량 경량화 달성

### 4. HWP / HWPX 파일 예외 가이드
* **지원 포맷:** HWP, HWPX
* **동작 원리:** 바이너리 구조가 폐쇄적인 한글(HWP) 파일의 특성을 고려하여 업로드 시 즉시 알림창(Modal/Alert)을 띄우고, "PDF나 워드(DOCX) 파일로 변환하여 업로드"하도록 안내 메시지 출력

### 5. Office 문서(DOCX / PPTX) 처리
* **지원 포맷:** PPT, PPTX, DOC, DOCX
* 내부 XML 패키징 내 미디어 축소 시뮬레이션 및 다운로드 플로우 제공

## 📊 파일 형식별 압축 전략

| 포맷 | 압축 방식 | 압축 원리 및 처리 전략 |
| :--- | :--- | :--- |
| **JPG / PNG** | 클라이언트 Canvas 압축 | Canvas 2D 컨텍스트에서 품질 계수(0.6) 조정 후 Blob 변환 |
| **PDF** | 스캔본 재조합 압축 | `PDF.js`로 각 페이지 렌더링 후 `jsPDF`로 이미지 기반 경량 PDF 재조합 |
| **DOCX / PPTX** | 내부 미디어 패키지 최적화 | XML 컨테이너 기반 미디어 리소스 압축 프로세스 |
| **HWP / HWPX** | 변환 가이드 제공 | 포맷 특성상 브라우저 직접 압축 불가 안내 및 PDF 변환 유도 |

## 🛠 기술 스택

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **PDF 처리 엔진:** 
  * [PDF.js v2.16.105](https://mozilla.github.io/pdf.js/) (PDF 페이지 파싱 및 캔버스 렌더링)
  * [jsPDF v2.5.1](https://github.com/parallax/jsPDF) (클라이언트 사이드 PDF 생성 및 번들링)
* **Design:** Flexbox 기반 반응형 레이아웃, 모던 플랫 UI

## 💻 설치 및 실행 방법

외부 서버나 복잡한 빌드 도구(`Node.js`, `Webpack` 등) 없이 단일 파일로 동작합니다.

### 1. 저장소 클론 또는 다운로드
```bash
git clone https://github.com/your-username/smart-doc-compressor.git
cd smart-doc-compressor
```

### 2. 로고 파일 준비
동일 디렉터리에 상단 헤더에 들어갈 `logo.png` 파일을 배치합니다.  
*(이미지가 없을 경우 기본 플레이스홀더 로고로 자동 대체됩니다.)*

### 3. 브라우저로 실행
`index.html` 파일을 더블 클릭하거나 브라우저(Chrome, Edge, Safari 등)로 드래그하여 실행합니다.

## 📝 사용 가이드

1. **로고 확인:** 상단 좌측 로고를 누르면 공식 사이트([nanalab.kr](https://nanalab.kr))로 새 창 이동합니다.
2. **파일 등록:**
   * 드롭존 중앙의 **Select Files** 버튼을 클릭하거나,
   * 탐색기에서 파일을 드롭존 영역(`Upload or Drop your file!`)으로 끌어다 놓습니다.
3. **압축 진행:** 각 파일별로 하단 목록에 프로그레스 바가 생성되며 진행률(%)이 표시됩니다.
4. **결과 파일 다운로드:** 진행이 완료되면 녹색 **다운로드** 버튼이 활성화됩니다. 클릭 시 `compressed_파일명` 형식으로 저장됩니다.
