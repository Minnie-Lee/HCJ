# Smart Image Resizer (스마트 이미지 리사이저)

웹 브라우저 상에서 간편하게 사진의 종횡비를 조절하고, 여백 채우기(Padding) 또는 영역 잘라내기(Crop) 방식으로 리사이징할 수 있는 클라이언트 사이드 이미지 편집 웹 애플리케이션입니다.

---

## 📌 주요 기능 (Key Features)

1. **헤더 & 브랜딩**
   - 좌측 상단 로고 이미지(`logo.png`) 클릭 시 [https://nanalab.kr](https://nanalab.kr)로 연결
   - 우측 상단 "Smart Image Resizer" 프로젝트 타이틀 표시

2. **편리한 이미지 업로드**
   - 파일 선택 버튼 지원
   - 드래그 앤 드롭(Drag & Drop)을 통한 다중 파일 업로드 지원

3. **다양한 종횡비(Aspect Ratio) 프리셋 & 커스텀 지원**
   - 기본 프리셋: `1:1`, `3:4`, `4:3`, `9:16`, `16:9`
   - 사용자 정의(Custom) 종횡비 직접 입력 기능 (가로:세로 비례값)

4. **2가지 변환 모드**
   - **Padding (여백 유지)**: 원본 비율을 보존하면서 대상 비율에 맞춰 여백을 추가 (기본 여백 흰색 및 컬러 피커를 통한 색상 커스텀 지원)
   - **Crop (자르기)**: 대상 비율에 맞게 원본 이미지의 중앙을 기준으로 잘라내어 비율 변환

5. **실시간 작업 현황 & 개별 다운로드**
   - 업로드된 이미지들의 썸네일과 파일명 목록 표시
   - 이미지별 작업 진행 상황을 보여주는 프로그레스 바(Progress Bar)
   - 변환 작업 완료(100%) 시 개별 다운로드 버튼 자동 활성화

6. **일괄 ZIP 압축 다운로드**
   - 등록된 모든 이미지의 변환이 완료되면 '일괄 다운로드' 버튼 활성화
   - `JSZip`을 활용하여 변환된 이미지들을 하나의 `.zip` 압축 파일로 한 번에 다운로드

---

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS ES6+)
- **Canvas API**: 브라우저 내 이미지 리사이징, 크롭, 배경색 채우기 처리
- **Libraries**: [JSZip](https://stuk.github.io/jszip/) (클라이언트 사이드 ZIP 파일 압축 및 생성)

## 🚀 실행 방법 (Getting Started)

별도의 백엔드 서버나 빌드 도구 설치 없이 브라우저에서 바로 실행할 수 있습니다.

1. 저장소를 클론하거나 코드를 다운로드합니다.
2. 같은 폴더에 `logo.png` 이미지를 위치시킵니다. (누락 시 텍스트 대체)
3. `index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등의 모던 웹 브라우저에서 실행합니다.

---

## 📖 사용 가이드 (How to Use)

1. **종횡비 및 모드 선택**: 원하는 캔버스 비율(`1:1`, `16:9` 등)과 변환 모드(`Padding` 또는 `Crop`)를 선택합니다. Padding 선택 시 원하는 여백 색상을 지정할 수 있습니다.
2. **이미지 추가**: 편집할 이미지들을 드래그 앤 드롭 영역에 끌어다 놓거나 '파일 선택' 버튼으로 추가합니다.
3. **진행 상태 확인**: 각 썸네일 옆 프로그레스 바를 통해 작업 상태를 확인합니다.
4. **다운로드**:
   - 개별 사진: 각 항목 우측의 '다운로드' 버튼 클릭
   - 전체 사진: 모든 변환이 끝나면 상단의 '일괄 다운로드 (.zip)' 버튼 클릭
