GYEONGJU SCHOOL TRIP — 경주 MT 웹페이지

Google Apps Script(GAS)로 배포하는 1페이지 학교/동아리 MT 안내 웹앱입니다. 일정, 이동 경로, 예산, 준비물 체크리스트를 한 페이지에 담고, 모바일로 바로 접속할 수 있도록 QR코드를 제공합니다.

파일 구성
파일	역할
code.gs	GAS 서버 스크립트. doGet()이 index.html을 렌더링해서 웹앱으로 서빙합니다.
index.html	페이지 전체(마크업 + CSS + 약간의 JS)가 들어있는 단일 템플릿 파일입니다.
배포 방법
script.google.com에서 새 프로젝트를 만듭니다.
기본 생성되는 코드.gs(또는 Code.gs) 내용을 이 저장소의 code.gs 내용으로 덮어씁니다.
프로젝트에 HTML 파일을 하나 추가하고 파일명을 정확히 **index**로 지정한 뒤, 이 저장소의 index.html 내용을 붙여넣습니다. (GAS는 파일명 기준으로 템플릿을 찾으므로 index.html이 아니라 index로 저장해야 합니다.)
상단 메뉴 배포 > 새 배포를 클릭합니다.
유형은 웹 앱을 선택합니다.
실행 사용자: 나
액세스 권한: 링크가 있는 모든 사용자 (팀원들도 봐야 하므로)
배포를 완료하면 나오는 웹 앱 URL이 실제로 공유할 주소입니다.
내용을 수정한 뒤에는 배포 > 배포 관리에서 기존 배포를 **수정(새 버전으로 배포)**해야 같은 URL에 최신 내용이 반영됩니다. (새 배포를 만들면 URL이 바뀝니다.)
QR코드 기능

페이지 하단(체크리스트와 푸터 사이)에 QR 섹션이 있습니다.

code.gs의 doGet()이 ScriptApp.getService().getUrl()로 현재 배포된 웹앱의 실제 주소를 가져와 템플릿 변수 appUrl로 넘겨줍니다.
index.html은 이 값을 api.qrserver.com QR 생성 API에 넘겨 <img> 태그로 QR 이미지를 만듭니다. 별도 JS 라이브러리 설치가 필요 없습니다.
배포를 갱신해도(같은 배포를 "새 버전으로 배포") URL이 그대로라면 QR도 그대로 유효합니다.
스캔 시 브라우저로 페이지가 바로 열리므로, MT 당일 이동 중 팀원들이 일정·경로·예산을 폰으로 바로 확인할 수 있습니다.

참고: 배포 > 새 배포로 완전히 새 배포를 만들면 URL이 바뀌므로, 이미 공유한 QR/링크는 무효가 됩니다. 이 경우 페이지를 다시 열어(웹앱 접속) QR을 재생성하거나, 필요하면 배포 URL을 고정해주는 방식(예: 항상 같은 배포를 "관리"에서 업데이트)을 유지하는 것을 권장합니다.

커스터마이징
색상(검정/노랑/빨강 톤)은 index.html 상단 <style>의 CSS 변수(--black, --dark, --white, --yellow, --red, --gray, --light-gray)에서 일괄 관리됩니다.
일정(SCHEDULE), 경로(ROUTE), 예산(BUDGET), 체크리스트, QR 섹션은 각각 <!-- ===== --> 주석으로 구분되어 있어 원하는 섹션만 찾아 텍스트를 수정하면 됩니다.
반응형 기준점은 max-width: 760px(태블릿/모바일 전환)과 max-width: 390px(소형 모바일)입니다.
