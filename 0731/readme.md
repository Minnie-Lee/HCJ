# 🌊 BUSAN — 부산 공식 관광 안내 플랫폼 (BUSAN TOUR)

> **0731 조별과제 최종 결과 보고서**  
> 부산의 대표 랜드마크, 로컬 맛집, 다채로운 축제와 대중교통 정보를 제공하는 반응형 관광 안내 웹 서비스입니다.

---

## 📌 1. 프로젝트 개요 (Overview)
- **과제명**: 웹 프로그래밍 조별 실습 프로젝트
- **프로젝트명**: BUSAN 관광 안내 웹 가이드
- **제출 폴더**: `HCJ/0731/`
- **핵심 목표**: 국내외 방문객을 위한 직관적 UI, 다국어 지원, 모바일 친화적 반응형 웹 환경 구현

---

## ✨ 2. 주요 기능 및 구현 내용 (Key Features)

### 🎨 몰입형 인터랙티브 히어로 섹션 (Hero Section)
- **풀스크린 비주얼 슬라이더**: 광안대교 야경, 감천문화마을 등 부산 대표 랜드마크 고화질 연출
- **Ken Burns 트랜지션**: 슬라이드 활성화 시 부드러운 확대 애니메이션(`kenburns 9s ease-out`) 적용
- **다기능 컨트롤러**: 좌우 네비게이션 버튼, 인디케이터 닷(Dots), 실시간 페이지 번호 카운터

### 🌐 다국어 지원 인터페이스 (Multilingual Support)
- 4개 국어(한국어, 일본어, 영어, 중국어) 전환 지원 인터페이스
- `data-ko`, `data-ja`, `data-en`, `data-zh` 데이터 속성을 활용한 텍스트 렌더링 구조 설계

### 🧭 직관적인 내비게이션 및 바로가기
- **4대 메인 카테고리**:
  - 📍 **관광명소 (`tour.html#spots`)**: 해운대, 광안리, 자갈치시장 등 대표 명소
  - 🍽️ **맛집 (`tour.html#spots`)**: 부산 밀면, 돼지국밥, 씨앗호떡 등 로컬 미식 가이드
  - 🎆 **축제·행사 (`tour.html#districts`)**: 부산국제영화제(BIFF), 불꽃축제 등
  - 🚇 **교통정보 (`tour.html#transit`)**: 도시철도, 시내버스 노선 및 환승 시스템
- **테마 칩(Theme Chips)**: 주요 여행 테마별 다이렉트 앵커 링크 제공
- **플로팅 프로모션 카드**: 추천 여행 코스 및 시즌별 기획 페이지 연결

## 🛠️ 3. 개발 환경 및 기술 스택 (Tech Stack)

| 구분 | 기술 / 도구 | 상세 설명 |
| :--- | :--- | :--- |
| **Markup** | HTML5 | 시맨틱 태그 구조 설계, 웹 표준 준수 |
| **Styling** | CSS3 | Flexbox 레이아웃, CSS 루트 변수(`:root`) 활용 |
| **Typography** | Google Fonts | `Song Myung`(타이틀), `Black Han Sans`(포인트), `Gowun Dodum`(본문) |
| **Responsive** | CSS Media Query | 태블릿·모바일 뷰포트 대응 (`820px`, `900px` 브레이크포인트) |
| **Accessibility** | CSS Media Feature | 모션 민감 사용자를 위한 `prefers-reduced-motion` 대응 |

### 🎨 디자인 테마 컬러 (Color Palette)
- **Deep Navy (`#071526`) / Navy (`#0b2036`)**: 부산 밤바다의 깊이감을 표현하는 메인 배경색
- **Teal (`#1c6e8c`)**: 청량한 부산 해변과 파도를 상징하는 보조색
- **Coral (`#ff6f52`)**: 활기찬 축제와 에너지를 나타내는 포인트 CTA 컬러
- **Gold (`#f0b642`)**: 야경과 하이라이트 텍스트 강조색
- **Paper (`#f6efe0`)**: 눈의 피로도를 낮추는 가독성 중심 폰트 컬러
