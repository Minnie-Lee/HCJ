# 📝 글자 수를 세어 주는 웹 앱 (Word Counter)

텍스트를 입력하면 실시간으로 **공백 포함 글자 수**, **바이트(Byte) 용량**, **공백 제외 글자 수**를 계산해 주는 모던하고 깔끔한 웹 애플리케이션입니다.  
한국어, 영어, 일본어 3개 국어 인터페이스 전환을 지원합니다.

---

## ✨ 주요 기능

* **실시간 텍스트 분석**: 별도의 버튼 클릭 없이 텍스트를 입력하거나 붙여넣는 즉시 글자 수와 용량을 집계합니다.
* **정밀한 바이트(Byte) 계산**:
  * **ASCII 영문/숫자/기호/공백**: `1 Byte`
  * **한글 / 일본어(히라가나·가타카나) / 한자**: 전각 문자 규격에 맞춘 `2 Byte` 계산
* **3개 국어 지원**: 한국어, 영어, 일본어 UI 전환 지원
* **미니멀 & 모던 디자인**: 토스/애플 스타일의 군더더기 없는 플랫 웜그레이 톤과 부드러운 인터랙션 적용
* **반응형 웹 지원**: 데스크톱과 모바일 화면 크기에 맞춰 레이아웃 자동 최적화

---

## 🛠️ 기술 스택

* **HTML5**: 웹 문서 구조화
* **CSS3**: 모던 플랫 UI 스타일링 및 Flexbox/Grid 기반 반응형 레이아웃
* **JavaScript (Vanilla JS)**: 유니코드 기반 바이트 계산 및 다국어 텍스트 바인딩

---

## 🚀 실행 방법

1. 프로젝트 소스 코드를 복사하여 `index.html` 파일로 저장합니다.
2. 저장한 `index.html` 파일을 Chrome, Safari, Edge 등 웹 브라우저에서 더블 클릭하여 실행합니다.
3. 별도의 서버 설치나 외부 라이브러리 연동 없이 즉시 구동됩니다.
